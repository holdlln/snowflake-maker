## 접힌 면을 원래 종이에 연결하는 방법

### 1. Rabbit Ear의 면 변환

`paper.js`의 `foldPaper`는 직전 단계의 FOLD 그래프를 복제하고 그 그래프에 `flatFold`를 적용합니다. 따라서 다음 호출에도 이전 접기에서 생긴 정점, 변, 면, 행렬이 전달됩니다. 선택점의 외적 부호가 음수면 두 점으로 만든 선 벡터를 뒤집습니다. Rabbit Ear는 벡터 기준 외적이 양수인 쪽을 넘깁니다.

각 면의 `faces_matrix2`는 원래 점을 현재 위치로 옮기는 여섯 수 `[a,b,c,d,tx,ty]`입니다. 이 배열은 `(x,y) → (a·x + c·y + tx, b·x + d·y + ty)`를 뜻합니다. 예를 들어 `x=0.50`에서 왼쪽을 넘기면 왼쪽 면의 반사 행렬은 `[-1,0,0,1,1,0]`이고, 오른쪽 면은 항등 행렬입니다.

```text
원래 종이                          접은 위치
왼쪽 면 (0.20, 0.30) ── x ↦ 1−x ──┐
                                      ├── (0.80, 0.30)에서 두 겹
오른쪽 면 (0.80, 0.30) ── 그대로 ──┘
```

`flatFold`는 이전 면 번호별로 새 면 번호 목록을 반환합니다. 앱은 이 목록을 역으로 읽어 각 새 면에 직전 단계의 `parent`를 기록합니다. 실제 반사 결과와 일치하는 행렬인지 확인한 뒤에만 새 단계를 이력에 넣습니다.

### 2. iCurve로 접힌 면마다 교집합 구하기

`cut.js`는 `CurveBuilder`로 면의 다각형과 사용자 경로를 만들고 `CurveOverlay`에 넘깁니다. **잘라내기**는 면마다 차집합 `면 − 영역`을 남기고, **남기기**는 교집합 `면 ∩ 영역`을 남깁니다. 두 결과는 해당 면의 역행렬로 원래 종이 좌표에 저장합니다. 같은 화면 위치에서 네 면 중 두 면만 영역과 겹치면 잘라내기에서는 두 면만 잘리고, 남기기에서는 두 면의 겹친 부분만 보존됩니다. 면의 테두리를 가로지르면 교집합도 그 테두리에서 잘립니다.

베지어의 시작점, 끝점, 두 조절점은 같은 행렬을 적용합니다. 예를 들어 위 왼쪽 면의 접힌 좌표에서 조절점이 `(0.75, 0.25)`라면 역반사로 원래 종이의 `(0.25, 0.25)`에 돌아갑니다. 아핀 변환은 베지어를 구성하는 점들의 가중합과 교환되므로 점과 조절점을 옮긴 뒤에도 같은 곡선을 얻습니다.

### 3. 접기 이력으로 한 단계씩 펼치기

최종 면에서 `parent`를 거슬러 표시할 단계의 면을 찾습니다. `app.js`의 `renderMaterial`은 원래 좌표로 저장한 남은 조각에 그 조상 면의 행렬을 적용합니다. 접힌 점 `q`로 쓰면 `원래 점 = T최종⁻¹(q)`, `중간 단계 점 = T조상(원래 점)`입니다. 최종 단계의 여러 조각이 같은 조상 면으로 돌아오면 한 SVG 경로에 묶어서 이음선을 숨깁니다.

가로 중앙선에서 아래쪽, 세로 중앙선에서 왼쪽을 넘긴 경우를 생각해 보세요. 접힌 곳의 점 `(0.80, 0.30)`은 세로 접기를 풀었을 때 `(0.20, 0.30)`과 `(0.80, 0.30)`에 나타납니다. 가로 접기까지 풀면 아래쪽의 `(0.20, 0.70)`과 `(0.80, 0.70)`도 나타납니다.

## 검증 기록

2026-11-10에 Windows의 Python 3.12.2 정적 서버와 Chromium 기반 Codex 내장 브라우저에서 최종 저장소 폴더의 앱을 실행했습니다.

| 브라우저 조작 | 확인한 결과 |
| --- | --- |
| 처음 열기 | 정사각형 1면, 접기 0회, WASM 초기화 완료 |
| 가로·세로 중앙 접기 후 내부 베지어 오리기 | 면 수 1 → 2 → 4, 잘린 면 4개. 펼치기 1회 후 겹쳐 보이는 구멍 두 곳, 완전히 펼친 뒤 대칭 구멍 네 곳 |
| 비중앙 세로 접기 후 사선 접기 | 최종 4면 중 2면만 잘림. 두 번 펼쳤을 때 내부 구멍 하나와 오른쪽 가장자리 파임 하나가 보임 |
| 닫힌 경로의 조절점 드래그 | 화면의 베지어와 SVG `C` 명령의 조절점 좌표가 함께 갱신됨 |
| 동일 점 반복, 종이 밖 접는 선, 종이 밖 오리기 | 안내가 표시되고 기존 종이 경로와 접기 횟수가 유지됨 |
| 펼치기 직후 되돌리기, 초기화 | 한 단계 앞의 겹과 구멍을 다시 표시. 초기화 후 접기 0회, 자르기 전 정사각형 1면 |
| 영역 남기기 | 두 번 접은 종이에서 밝게 미리 보인 부분을 보존. 두 단계 펼친 뒤 연결된 결정 모양을 확인 |
| 눈 내리는 밤 | 남기기로 만든 결정과 베지어 구멍을 낸 종이를 각각 보관. 새로고침 후 두 SVG 윤곽이 복원되고, 서로 다른 두 모양이 함께 내려옴. 일시 정지 확인 |

같은 기하 모듈을 Node.js에서 재현할 수 있습니다. 저장소 루트에서 다음 명령을 실행합니다.

```powershell
node --test .\paper-cut-simulator\verify.mjs
```

Node.js 24에서 7개 검사를 통과했습니다. 양쪽 반사 방향, 대칭 구멍과 중간 단계의 끝점·조절점 복원, 4면 중 2면 절단 및 오른쪽 변 파임, 잘못된 접기와 종이 밖 절단, 이미 없어진 종이의 재절단, 사선 접기에서의 남기기, 연속 편집에서 기존 구멍 보존을 검사합니다.

## 45~55초 시연 순서

1. **0~8초.** 새 정사각형에서 `y=0.50` 가로선을 잡고 아래쪽을 넘깁니다. 이어 `x=0.50` 세로선을 잡고 왼쪽을 넘깁니다. 면 수가 4가 되는 것을 보여 줍니다.
2. **8~25초.** 접힌 오른쪽 위 조각에 `(0.65,0.35)`를 찍습니다. 베지어로 `(0.80,0.35)`, 직선으로 `(0.75,0.45)`를 잇고 닫습니다. 첫 조절점을 `(0.66,0.09)` 근처로 끌어 분홍색 미리보기가 바뀌는 것을 보여 준 뒤 확정합니다.
3. **25~37초.** 한 단계씩 두 번 펼칩니다. 구멍 두 곳이 먼저 보이고, 마지막에는 네 곳이 보이는 것을 보여 줍니다.
4. **37~52초.** 비중앙·사선 검증 결과를 별도 장면으로 이어 붙입니다. 네 면 중 두 면만 오려졌다는 숫자와, 펼쳤을 때 내부 구멍과 가장자리 파임이 다른 위치에 남은 모습을 보여 줍니다.

비중앙 장면을 재현하려면 `(0.35,0.10) → (0.35,0.90)`을 찍고 `(0.15,0.50)` 쪽을 넘기세요. 이어 `(0.35,0.25) → (0.95,0.50)`을 찍고 `(0.50,0.10)` 쪽을 넘깁니다. `(0.80,0.85)`에서 베지어로 `(0.95,0.65)`, 직선으로 `(0.90,0.75)`를 이어 닫은 뒤 첫 조절점을 `(0.76,0.49)` 근처로 이동합니다. 확정 후 **마지막 오리기**에 2면이 표시됩니다.

과제 안내서의 최종 제출 형식은 `{학번}_{이름}_P2.zip`입니다. PLATO에 제출할 때 위 파일에 **30초~1분 MP4**와 **3~5쪽 PDF**를 더합니다. PDF는 주제와 라이브러리 선택 이유, 위 세 단계 원리, 추가한 기능과 검증 결과, 해결 과정, AI 사용과 본인 수정 기록으로 구성할 수 있습니다.

## 알려진 제한

- 접기는 두께가 0인 종이의 2D 평면 반사로 모델링합니다. 화면에는 각 접기·펼치기 단계의 결과를 표시합니다.
- 오리기를 확정한 뒤에는 같은 접힘에서 추가로 오리거나 펼칠 수 있습니다. 접기를 바꾸려면 되돌리기나 초기화로 돌아갑니다.
- 정점에 아주 가까운 접는 선이나 폭이 아주 작은 조각에서는 허용 오차로 인해 접기가 거절되거나 WASM 변환에서 미세한 윤곽이 단순화될 수 있습니다. 접기를 많이 반복하면 면 수와 계산 시간이 늘어납니다.
- 작업 중인 종이는 현재 탭에 있고, 보관한 결정은 접속 주소별 브라우저 저장소에 최대 16개 저장됩니다. 브라우저나 포트가 바뀌면 별도 보관함이 열립니다.
